# Project Description

## Problem

Students may study many topics across subjects but have difficulty tracking what they studied, how well they performed, and which topics need revision.

## Proposed Solution

The Adaptive Learning Intelligence System (ALIS) provides a lightweight dashboard where students can record topics and scores. The system computes a retention score and converts it into revision-priority categories.

## Key Contribution

The project combines:

- Student authentication
- Topic-level academic tracking
- A transparent retention rule
- Revision alerts
- Dashboard analytics
- Subject-wise performance visualization

## Current Scope

The current implementation is designed as a portfolio/academic prototype using Streamlit and CSV storage. It does not include a trained recommendation model, database backend, automated calendar scheduling, or scientifically validated retention prediction.
